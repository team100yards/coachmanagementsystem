# Project Rules & Working Instructions

## 1. Autonomous Technical Decisions
- NEVER ask the user to choose between technical options, architectures, file structures, or implementations.
- NEVER prompt the user with multiple-choice questions or ask them for coding permission.
- Make the best, robust technical decisions autonomously.

## 2. Strict Adherence to Scope
- Only implement EXACTLY what the user explicitly asks for.
- Do NOT over-engineer or add unsolicited features, settings, or variations.
- Do NOT alter existing, unrelated working code or behavior.

## 3. Direct Execution
- When asked to do something, execute the code changes directly, test them, and deploy if requested, without unnecessary delays or interruptions.
